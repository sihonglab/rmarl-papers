# 7. Strategically Robust Multi-Agent Reinforcement Learning with Linear Function Approximation

## Taxonomy
- **Robustness / perturbation type targeted**: Strategic/opponent robustness (robustness to opponent misspecification and partner perturbation/cross-play), payoff/approximation-error robustness (Lipschitz stability of the equilibrium map under estimated-payoff perturbations), plus environment/model uncertainty and risk-sensitivity via convex risk measures and distributionally robust optimization.
- **Method paradigm**: Risk-Sensitive / Risk-Averse Quantal Response Equilibrium (RQRE), bounded rationality (quantal response, entropy regularization), convex/coherent risk measures with dual (DRO) representation, optimistic value iteration with linear function approximation, finite-sample regret analysis.
- **Keywords**: Risk-Sensitive Quantal Response Equilibrium (RQRE), general-sum Markov games, linear function approximation, distributional robustness, bounded rationality, regret bounds

## TL;DR
The paper proposes RQRE-OVI, an optimistic value iteration algorithm that computes the Risk-Sensitive Quantal Response Equilibrium (a unique, smooth, tractable alternative to Nash) in general-sum Markov games with linear function approximation, and provides the first finite-sample regret bounds showing how rationality and risk-sensitivity parameters trade off expected performance against robustness.

## Problem & Motivation
Provably efficient and robust equilibrium computation in general-sum Markov games is a core MARL challenge: Nash equilibrium is computationally intractable in general and brittle due to equilibrium multiplicity and sensitivity to approximation error. Prior work (Cisneros-Velarde and Koyejo, 2023) extended Nash Q-learning to the linear function approximation regime (NQOVI) with finite-sample regret bounds scaling in feature dimension, but the algorithm must solve for a Nash equilibrium at every stage game and episode, inheriting both Nash's intractability and the instability of the Nash correspondence (arbitrarily small payoff perturbations can produce discontinuous jumps in the selected equilibrium). Under function approximation, where Q-values are estimated with error, this brittleness makes the core equilibrium computation ill-conditioned with respect to the algorithm's own approximation errors. This motivates equilibrium concepts that are simultaneously tractable, stable under payoff perturbations, and amenable to scalable RL with formal guarantees.

## Robustness Setting
- **Threat model / uncertainty set**: Three separated sources of risk/uncertainty are modeled via convex risk measures with a dual (worst-case-expectation) representation: (i) environment risk — randomness in the next state xh+1 ~ Ph(·|x,a); (ii) policy risk — strategic risk-aversion to randomness in opponents' actions a−i; and bounded rationality via entropy regularization. Each player minimizes a risk-adjusted loss ρi(−ui) that, by duality, equals a worst-case expectation over an adversarial distribution pi over opponents' joint actions minus a convex penalty φi(pi, π−i) penalizing deviation from the reference policy π−i. RQRE thus admits a (penalized) distributionally robust optimization interpretation; ambiguity-set DRO (e.g., optimal-transport balls, Lanzetti et al., 2025) arises as a special case. The canonical instance is the entropic (KL-penalty) risk measure with temperature τi controlling risk aversion (τi→0 recovers risk-neutral expectation, τi→∞ yields worst-case/minimax).
- **Setting**: General-sum episodic Markov games; finite action spaces but arbitrarily large/continuous state spaces via linear function approximation; evaluated on cooperative/coordination benchmarks under self-play and cross-play; online (regret minimization over episodes), centralized optimistic value iteration.

## Method
- Studies the Risk Quantal Response Equilibrium (RQRE) of Mazumdar et al. (2025): each player's equilibrium policy minimizes its risk-adjusted loss plus a strictly convex regularizer (1/ϵi)νi(πi), where ϵi is the bounded-rationality (precision) parameter; this yields a unique, smooth equilibrium that smooths the equilibrium correspondence.
- Extends the static RQRE to finite-horizon risk-sensitive Markov games via a stage-wise risk-regularized Bellman recursion: an environment-risk operator Re_{i,h} (applied to next-state randomness) defines Qi_h, and a policy-risk operator Rp_{i,h} (applied to opponents' actions) plus the regularizer defines the value Vϵi_{i,h}; the RQRE is the fixed point of the smoothed best-response map at every stage, state, and player.
- Proposes RQRE-OVI (Algorithm 1): optimistic value iteration over linear Markov games. At each episode and backward stage it forms the ridge-regression design matrix Λk_h, solves an approximate stage RQRE via a subroutine RQREε (replacing the Nash oracle), regresses noisy risk-adjusted targets ŷ to obtain wi,k_h, and clips the optimistic Q-estimate with an exploration bonus β·sqrt(ϕᵀ(Λk_h)⁻¹ϕ) capped at B.
- In the entropic/entropy-regularized special case, the policy-risk value admits a closed-form (KL-regularized log-sum-exp); the value range is B = max_i H(1 + log|Ai|/ϵi), exposing how rationality ϵi controls scale, and equilibria are computable via no-regret learning (extragradient/Mirror-Prox, multiplicative weights, iterative best response).
- The exploitability/regret notion measures how much each player could gain by a smoothed best-response deviation; it is zero exactly when πk is an RQRE.

## Theoretical Contributions
- **Finite-sample regret bound (Theorem 2, Corollary 1)**: reg(K) ≤ Õ(Lenv·B·sqrt(K·d³·H³)) + KH(εenv + Lenv(εpol + εeq)), the first regret guarantees for optimistic MARL with linear function approximation, risk-sensitivity, and approximate (not oracle Nash) equilibrium computation; solver error scales as εeq = O(B·sqrt(Δeq/τmin)), so greater risk aversion relaxes solver-accuracy requirements, while weaker entropy regularization (larger ϵ) shrinks B and the leading term.
- **Distributional robustness (Proposition 1, Proposition 2)**: RQRE are distributionally robust and strictly generalize ambiguity-set / hard-DRO equilibria and Nash, with the inclusion chain RQRE ⊃ Penalized DRO Equilibrium ⊃ Hard ambiguity-set DRO Equilibrium ⊃ Nash Equilibrium; Lagrange multipliers determine ambiguity-set sizes.
- **Lipschitz stability (Corollary 2)**: the RQRE policy map is Lipschitz continuous in estimated payoffs, ‖πRQRE(Q) − πRQRE(Q̃)‖₁ ≤ (c/μ)‖Q − Q̃‖∞ with μ = 1/ϵ + ταp, a property Nash provably lacks (Example 3 shows no finite uniform Lipschitz constant exists for Nash under multiplicity).
- **Policy convergence under approximation error (Proposition 3)**: bounded parameter-estimation error δh implies bounded policy deviation ‖π̂h − π⋆h‖₁ ≤ (c/μ)δh and value error O(HBδ̄/μ) when the environment risk operator is non-expansive (Lenv ≤ 1).

## Experiments
- **Environment/Benchmark**: Two multi-agent coordination benchmarks — a dynamic spatial Stag-Hunt game (9×9 grid) modified from the Melting Pot suite (Agapiou et al., 2022); and Overcooked (Gessler et al., 2025), using the JaxMARL implementation (Rutherford et al., 2024).
- **Baselines**: QRE-OVI (risk-neutral quantal response) and NQ-OVI / NQOVI (Nash Q-learning with optimistic value iteration, Cisneros-Velarde and Koyejo, 2023). RQRE-OVI evaluated across a range of risk-aversion parameters τ.
- **Evaluation metrics**: Self-play team return during training; cross-play retention R(δ)/R(0) under a perturbed partner (partner deviates to a fixed/random action with probability δ), averaged over 200 rollouts per noise level; cross-play ego reward vs. partner reward with unseen partners trained under different algorithms.

## Key Results
- In Stag-Hunt self-play, the risk-aversion parameter τ controls equilibrium selection: high-τ agents (τ ≥ 0.5) reach the payoff-dominant (stag, stag) outcome (team return ~60) while low-τ agents (τ ≤ 0.05) settle on the robust risk-dominant (hare, hare) outcome (~20); QRE-OVI and NQ-OVI converge to intermediate, payoff-dominant returns.
- Under partner perturbation, risk-averse (low-τ) agents degrade gracefully and retain high performance across noise levels, while less-risk-averse, QRE, and NQOVI agents that converged to the fragile stag/payoff-dominant equilibrium suffer sharp retention drops — the predicted robustness–performance tradeoff.
- In Overcooked self-play, RQRE-OVI and QRE-OVI converge to higher team returns than NQ-OVI (attributed to Nash's equilibrium-selection problem disrupting sustained coordination); RQRE retains 60–80% of performance at δ = 0.3 while NQOVI, QRE, and high-τ RQRE drop below 40%.
- In Overcooked cross-play with unseen partners, RQRE agents achieve equal or higher ego reward across nearly all pairings (points above the diagonal), with moderate τ (e.g., τ = 0.01) yielding ~2–3× the reward of the NQ-OVI partner; QRE performs comparably to NQ-OVI, indicating risk aversion (not bounded rationality alone) is the key driver of cross-play robustness.

## Limitations & Future Work
- The algorithm uses a centralized exploration bonus; decentralizing the bonus term is left to future work (possibly feasible under monotonicity conditions established for RQRE in the infinite-horizon setting, Zhang and Mazumdar, 2025).
- Recovering risk neutrality (τ → 0) requires scaling the stage-solver duality gap Δeq = O(τmin·εeq²/B²) to maintain a fixed εeq, so the benefits depend on tunable risk/rationality parameters.
- A more fine-grained understanding of the role of risk sensitivity, including risk-seeking agents and asymmetric risk profiles across players, is identified as a future direction.

## Relevance to Survey
This paper sits at the intersection of the game-theoretic-equilibrium and distributionally-robust lines of robust MARL, proposing a tractable alternative to Nash (RQRE) whose robustness arises from bounded rationality and risk sensitivity rather than an explicit nature player. It connects the risk-sensitive MARL theme, the distributionally robust equilibrium / optimal-transport line (Lanzetti et al., 2025; Alizadeh et al., 2025), and the function-approximation/regret-analysis line for Markov games, while explicitly contrasting itself with environmental-uncertainty robust MARL (McMahan et al., 2024; Shi et al., 2024; Zhang et al., 2020 — paper #1 in this survey). Its Lipschitz-stability and cross-play robustness results provide a complementary "strategic robustness" angle to the worst-case model-uncertainty paradigm.

## Related Work (verbatim excerpts from the paper)
> _[Appendix A, Extended Discussion & Related Work — opening]_

"In this section we provide a detailed discussion of related literature. Our work studies the Risk Sensitive Quantal Response Equilibrium (RQRE) introduced by Mazumdar et al. (2025), which combines risk aversion with bounded rationality to yield a class of equilibria that is computationally tractable via no-regret learning in all finite-action, finite-horizon Markov games, provided agents exhibit a sufficient degree of risk aversion and bounded rationality. Zhang and Mazumdar (2025) extended these results to discounted infinite-horizon Markov games, proving contraction of the risk-averse quantal response Bellman operator and convergence of a Q-learning algorithm under monotonicity conditions."

> _[Appendix A — "Nash equilibrium methods in Markov games"]_

"The standard solution concept when studying multi-agent interactions from a game-theoretic perspective is the Nash equilibrium (Nash, 1950): a joint policy from which no agent can improve their outcome by unilaterally deviating. In a seminal work, Hu and Wellman (2003) introduced Nash Q-learning, the first extension of single-agent Q-learning to general-sum stochastic games. The core mechanism involves agents maintaining Q-functions over joint actions and performing updates based on the assumption that all participants will adopt Nash equilibrium behavior in the stage games. However, this original formulation provides only asymptotic guarantees. Building on this, Liu et al. (2021) provided the first finite-sample guarantees by incorporating optimism into the online learning process, an exploration bonus term that allows agents to efficiently learn an accurate model of the environment from a limited number of interactions. Despite these advancements, both works are restricted to the tabular setting, whose computational and memory costs scale prohibitively with the size of the state space. Moreover, computing Nash equilibria in general-sum games is computationally intractable in general (Daskalakis, 2013). This intractability has motivated alternative solution concepts such as correlated equilibria (Aumann, 1974) and coarse correlated equilibria (Moulin and Vial, 1978), but these rely on a shared correlation device and lack individual rationalizability, meaning each agent's learned policy carries no meaningful optimality guarantees unless all agents jointly follow the correlated recommendation. To address the scalability issues of tabular methods, Cisneros-Velarde and Koyejo (2023) proposed Nash Q-learning with Optimistic Value Iteration (NQOVI), extending the framework of Hu and Wellman (2003) to the linear function approximation regime and providing finite-sample regret bounds that scale with feature dimension rather than the size of the state space. As discussed in Section 1 & 4, a fundamental bottleneck persists: the algorithm requires solving for a Nash equilibrium at every stage game and every episode, inheriting both computational intractability and the instability of the Nash correspondence under payoff perturbations (Example 3). In the function approximation setting, where Q-values are necessarily estimated with error, this brittleness is especially problematic."

> _[Appendix A — "Bounded Rationality and Risk Aversion"]_

"Bounded rationality has a long history in behavioral game theory, where it was introduced to better predict the strategic behavior of human decision-makers known to be imperfect optimizers (Erev and Roth, 1998; Goeree and Holt, 1999; McKelvey and Palfrey, 1995). The standard formalization replaces exact best responses with quantal responses—stochastic policies that assign higher probability to higher payoff actions. In the context of multi-agent reinforcement learning, this modeling choice offers several important benefits. First, it provides a principled equilibrium selection since entropy-regularized response functions yield a unique, smooth equilibrium for any finite game, resolving the multiplicity and discontinuity issues inherent to Nash equilibrium (McKelvey and Palfrey, 1995). Second, bounded rationality reduces sensitivity to the approximation errors and non-stationarity unavoidable in learning settings, producing policies that trade off optimality against stability. Third, this formulation aligns naturally with modern reinforcement learning, where entropy-regularized objectives are widely employed as components of coherent decision-theoretic frameworks (Haarnoja et al., 2018; Mertikopoulos and Sandholm, 2016; Sokota et al., 2023).

Incorporating risk aversion addresses fundamental limitations of purely expected utility maximizing agents. Risk-sensitive objectives provide a principled mechanism for promoting safety and reliability by discouraging policies that achieve high average performance at the cost of rare but catastrophic outcomes, a failure mode that is especially pronounced in strategic, non-stationary environments. In game-theoretic settings, risk aversion acts as a form of robustification: by penalizing outcome variability, agents become less sensitive to modeling error, finite-sample noise, and strategic misspecification of opponents (Lanzetti et al., 2025; Mazumdar et al., 2025). This can further stabilize learning by biasing agents towards equilibria with lower variance and more predictable joint behavior, ultimately improving generalization across opponents and environments."

> _[Appendix A — "Risk sensitive multi-agent reinforcement learning"]_

"Our work leverages risk-aversion, where policies prefer actions with more certain outcomes in exchange for potentially lower expected return. Risk sensitivity in decision-making has its origins in Markov decision processes (Howard and Matheson, 1972), dynamic programming (Ruszczyński, 2010), and optimal control (Hernández-Hernández and Marcus, 1996), with a subsequent line of work integrating risk sensitivity into reinforcement learning (Heger, 1994; Lacotte et al., 2018; Mazumdar et al., 2017; Ratliff and Mazumdar, 2019; Shen et al., 2014; Singh et al., 2018). This work focuses on risk in multi-agent reinforcement learning. From a theoretical point of view, most existing works differ in the source of risk they address and make varying structural assumptions. Wang et al. (2024) considers risk-aversion to randomness in the stochastic payoffs via the conditional value at risk and requires strong monotonicity of the risk-averse game to guarantee convergence to a unique Nash equilibrium. Yekkehkhany et al. (2020) studies risk-aversion to the randomness induced by a population of mixed strategies of other agents in stochastic games, proving existence of equilibria in all finite games. Slumbers et al. (2023) considers risk-aversion to opponents' strategies by regularizing each agent's utility with the variance induced by the other agents' actions, and proves existence of their equilibrium concept, but the resulting formulation lacks tractability for general games. Lanzetti et al. (2025) takes a complementary approach, proposing a strategically robust equilibrium in which each agent optimizes against the worst-case opponent behavior within an ambiguity set, defined using optimal transport, and shows that such equilibria exist under the same assumptions as Nash equilibria and interpolate between Nash and maximin strategies. While these works focus on theoretical guarantees, recent empirical studies suggest risk-sensitive techniques extend to function approximators such as neural networks (Qiu et al., 2021; Shen et al., 2023). A related but distinct line of work is robust multi-agent reinforcement learning (McMahan et al., 2024; Shi et al., 2024; Zhang et al., 2020), which primarily addresses environmental uncertainty and worst-case parameters."

> _[Appendix A — "Linear function approximation in RL and Markov games"]_

"Foundational work by Tsitsiklis and Van Roy (1996) established asymptotic convergence guarantees in reinforcement learning algorithms with linear function approximation. Early results in providing finite-sample guarantees with linear function approximation was provided by Munos and Szepesvári (2008) studying fitted-value iteration under the assumption of access to a generative model of the environment. More recently, Jin et al. (2020) provided a provably sample efficient algorithm for linear MDPs in an online setting using optimism. Zhou et al. (2021) further refined these results, obtaining nearly minimax-optimal guarantees. Subsequently, linear function approximation has been extensively studied in the single-agent setting (Eaton et al., 2025; Wang et al., 2021; Yang and Wang, 2019; Zanette et al., 2020). Although less explored, extending these approaches to Markov games has attracted growing attention. The first line of works accomplished this in the two-player zero-sum setting (Chen et al., 2022; Qiu et al., 2022). Most recently, concurrent works Wang et al. (2023) and Cui et al. (2023) introduced independent linear function approximation to simultaneously address large state spaces while breaking the curse of multi-agents, achieving sample complexities polynomial in the number of agents rather than exponential. Dai et al. (2024) further refined these results with improved convergence rates. Most relevant to our work, Cisneros-Velarde and Koyejo (2023) extended Nash Q-learning (Hu and Wellman, 2003) to the linear function approximation regime, providing finite-sample regret bounds that scale with the feature dimension rather than the size of the state space. However, their algorithm requires solving for a Nash equilibrium at every stage game, inheriting both the computational intractability of Nash in general-sum games and its brittleness under payoff perturbations (as we show in Example 3). Moreover, Nash equilibria are not guaranteed to be unique in general-sum games, introducing an equilibrium selection problem that is particularly problematic under function approximation, where Q-values are necessarily estimated with error. In contrast, RQRE yields a unique, smooth equilibrium that is Lipschitz continuous in estimated payoffs (Corollary 2), and is individually rationalizable in the sense that each agent's learned Q-function carries meaningful optimality guarantees independent of whether other agents follow the equilibrium."

> _[Section 4.1, Distributional Robustness of RQRE]_

"In parallel to RQRE, several distributionally robust equilibrium concepts have been proposed, including strategically robust equilibrium via optimal transport (Lanzetti et al., 2025) and distributionally robust Nash equilibria (Alizadeh et al., 2025). The dual representation of the risk-adjusted loss (Section 2) reveals a direct connection between RQRE and distributionally robust optimization (DRO). In particular, the risk-adjusted loss (1) admits a natural interpretation as a penalized DRO objective: player i evaluates a strategy under an adversarial distribution over opponents' actions while paying a convex penalty for deviating from the reference distribution π−i. Consequently, RQRE corresponds to a fixed point of regularized best responses under penalized distributional robustness. Classical ambiguity-set DRO arises as a special case of (1)."
