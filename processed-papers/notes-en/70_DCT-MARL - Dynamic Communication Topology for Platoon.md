# 70. DCT-MARL: A Dynamic Communication Topology Based MARL Algorithm for Platoon Control

## Taxonomy
- **Robustness / perturbation type targeted**: Communication imperfections in V2V networks — time-varying communication delay and packet loss (non-ideal communication); robustness of cooperative platoon control to communication degradation.
- **Method paradigm**: Multi-Agent Reinforcement Learning (MARL) under Dec-POMDP; centralized-training decentralized-execution (CTDE) actor-critic with attention critic; dynamic communication topology via multi-key gated communication network; state augmentation for delay compensation; causal-inference-based communication target selection.
- **Keywords**: Connected Vehicle Platoon, Dynamic Communication Topology, Delay Compensation, Multi-Agent Reinforcement Learning, packet loss, string stability

## TL;DR
DCT-MARL is a MARL platoon-control algorithm that jointly handles time-varying V2V communication delay (via state augmentation with historical control action and delay) and packet loss (via a multi-key gated communication mechanism that dynamically adjusts the communication topology), improving string stability and driving comfort under non-ideal communication.

## Problem & Motivation
Connected vehicle platooning relies on reliable V2V communication for cooperative control, but real-world channels suffer time-varying delay and packet loss due to channel fading, signal obstruction, and spectral interference, degrading string stability, driving comfort, and safety. Prior delay-compensation control methods rely on simplified delay assumptions and lack sensitivity to time-varying delay; packet-loss mitigation (zero-order hold, interpolation, fallback modes) fails under high loss; recent dynamic-topology methods focus only on communication-quality metrics and overlook the context-dependent relevance of neighbor vehicles. Most works also treat delay or packet loss in isolation rather than jointly, and traditional optimization-based unified models rely on accurate system models that do not scale to dynamic, uncertain traffic. The paper aims to build a unified MARL framework that addresses delay and packet loss together while accounting for both inter-agent relevance and communication-quality dynamics.

## Robustness Setting
- **Threat model / uncertainty set**: Non-ideal V2V communication. (i) Communication delay ξ_{i,j}: vehicle i at time t receives information from vehicle j corresponding to time t − ξ_{i,j} instead of real-time data. (ii) Packet loss / communication failure: a communication agent may become unavailable at certain time steps, so a neighbor's information may be missing. Wireless channel modeled with Rayleigh small-scale fading plus large-scale path loss (WINNER+ B1, 3GPP) and shadow fading (Gaussian, σ = 3 dB). No explicit adversary or uncertainty-set optimization; robustness is achieved through state augmentation and adaptive topology.
- **Setting**: Cooperative (shared global reward); Dec-POMDP; centralized-training decentralized-execution (CTDE); online RL (model-free actor-critic, simulation/co-simulation training).

## Method
- **Dec-POMDP formulation**: Platoon of N+1 vehicles (leader index 0, followers 1..n) modeled as a Dec-POMDP ⟨N, S, U, P, R, O, γ⟩ with a shared global reward; each agent runs a decentralized policy π_i based on its observation-action history.
- **State augmentation for delay compensation**: Each vehicle's state is extended to S_{i,t} = {p_{i,t}, v_{i,t}, acc_{i,t}, u_{t−1}, ξ_{i,t}}, adding the most recent control input and the communication delay so the policy can infer dynamics under delayed/missing observations and preserve the Markov property; the reward is modified via conditional expectation (R̃_{i,t}) to adapt to delayed observations.
- **Multi-key gated communication network (dynamic topology)**: Each agent infers the relevance of potential communication partners using causal inference — a feedforward network computes KL divergence between P(u_i | u_{−ij}, o) and P(u_i, u_j | u_{−ij}, o) (from a softmax over the joint action-value function) to quantify how much agent j's actions would change agent i's policy. A Gumbel-Softmax binary gate (multi-key) selects m communication agents; a distance-weighting module assigns higher weights to closer vehicles for collision avoidance; the adjacency (trajectory) matrix A is constructed by aggregating keys, dynamically adjusting the directed communication graph in response to packet loss.
- **Actor-critic / CTDE training**: Each actor combines the gated communication network and an action-policy network. A centralized critic with multi-head attention aggregates joint observation-action pairs and estimates each agent's action-value; trained via TD learning, used only during training (decentralized execution). The objective maximizes an entropy-regularized return J_{π_i}(θ_i) = E[Q(s,u) + H(π_i(u_i|o_i(s,A))ρ(A|s))]. Training alternates: fix π_i and Q_i to update the graph policy ρ(A); then improve π_i and Q_i given the generated trajectories. A prior network (binary classifier) is trained to decide communication targets and the learned topology is retained for execution.

## Theoretical Contributions
None / mostly empirical. The paper provides problem formalization (Dec-POMDP with dynamic communication topology), the KL-divergence causal-influence criterion, and loss/objective derivations, but no convergence, sample-complexity, or equilibrium guarantees.

## Experiments
- **Environment/Benchmark**: Co-simulation of a six-vehicle platoon on a 1-km highway segment in SUMO, integrated with a Python communication simulator via the TraCI interface. Leader trajectory derived from real-world NGSIM data (eastbound I-80, San Francisco Bay Area). Wireless channel: Rayleigh fading + WINNER+ B1 path loss (3GPP, n = 2.15) + shadow fading (σ = 3 dB). Training for 1M steps, episode length 600, γ = 0.99, actor/critic learning rates 3.0×10⁻⁴ / 2.5×10⁻⁴, three random seeds.
- **Baselines**: DWOC (Dynamic Weights Optimization Control, traditional optimization-based) [20]; D3PG (DRL-based self-adaptive topology control) [16]; DEC-MARL (Delay-Compensated MARL, fixed topology) [25]; LEB-MARL (Learning-based MARL using causal inference) [26].
- **Evaluation metrics**: String stability index S_i (time-averaged weighted squared deviation in headway and relative velocity; lower is better); normalized driving comfort score G'_i (smoothness of acceleration changes; higher is better); average episodic return; runtime/inference efficiency.

## Key Results
- Against control baselines (Table II), DCT-MARL achieves the lowest string-stability values across all CAVs (e.g., CAV5: 0.103 vs. DWOC 0.312, D3PG 0.221) and the highest driving-comfort scores (e.g., CAV1: 0.827 vs. DWOC 0.512, D3PG 0.643), with especially strong disturbance suppression for rear vehicles (CAV3–CAV5).
- Against MARL baselines (Table III), DCT-MARL again gives the best string stability and comfort (e.g., CAV5 stability 0.103 vs. DEC-MARL 0.279, LEB-MARL 0.221), and converges faster to higher episodic reward than DEC-MARL and LEB-MARL.
- Inference is efficient: a 600-step simulation runs in ~3.7 s (~6 ms per decision step) on an Intel Core i5 2.0 GHz quad-core with 16 GB memory, well within the 100 ms control sampling period, supporting real-time deployment.
- Communication heatmaps show front-vehicle information dominates but rear-vehicle data is also significantly used, consistent with [5], validating the value of dynamic (vs. fixed) topology.

## Limitations & Future Work
- Evaluation is simulation/co-simulation only (SUMO + Python), with no real-vehicle/hardware validation.
- No theoretical guarantees (string stability, convergence) are proven; robustness is demonstrated empirically.
- Future work: further investigate the mechanism of non-ideal communication and explore joint optimization of communication and control for more adaptive and resource-efficient platoon coordination.

## Relevance to Survey
This paper sits on the "communication robustness / communication attacks" line of robust MARL, addressing robustness of cooperative MARL to non-ideal V2V communication (time-varying delay and packet loss) rather than environment/model uncertainty or adversarial agents. It connects the communication-aware / dynamic-topology MARL line (gated and attention-based communication: ITGCNet, Gated-ACML, I2C, NeurComm) with robust cooperative control under partial observability (Dec-POMDP, CTDE). It is a domain-application (connected vehicle platooning) instance that complements safety- and fault-tolerance-oriented robust MARL themes (safety-constrained reward, packet-loss/communication-failure tolerance).

## Related Work (verbatim excerpts from the paper)

> _[Section II.A, Related Work — Platoon Control under Unideal Communication Conditions]_

"Reliable V2V communication is essential for cooperative platoon control, however, packet loss and delay in practical V2V communication may induce performance degradation in the control system [3], [4].

To mitigate the negative impact of communication delay, a range of delay compensation based robust control strategies have been proposed [5]–[8], [27]. To address packet loss, traditional approaches employ techniques include Zero-Order Hold (ZOH) to maintain previous control inputs [9], historical data interpolation [10], [11], or fallback modes such as Adaptive Cruise Control (ACC) [12]–[14]. To enhance adaptability, some recent studies have introduced dynamic communication topology mechanisms that adjust weights based on communication quality, thereby mitigating the effects of communication packet loss [15], [16]. For example, Liu et al. [15] developed an traditional optimization-based method to adjust weights according to communication condition, whereas Wang et al. [16] proposed a self-adaptive topology control method based on a Dual-Decision Deterministic Policy Gradient (D3PG) algorithm for platoon control, which significantly enhances system resilience under fluctuating communication condition. However, these strategies primarily focus on communication quality metrics, overlooking the fact that in practical applications, the selection of communication targets should be context-aware and responsive to dynamic traffic conditions.

Furthermore, most existing studies address either delay or packet loss in isolation, making them insufficient for scenarios where both impairments coexist. In real-world environments, however, delay and packet loss frequently occur simultaneously, creating compounded challenges for platoon control systems. To address this, some recent studies have proposed unified models that simultaneously account for the effects of delay and packet loss [5], [9], [18]–[20]. For instance, Vegamoor et al. [18] modeled delay and packet loss simultaneously, and introduced a safety-aware constraint on distance errors between any two vehicles and derived a lower bound on safe time gaps to ensure string stability under unideal communication scenarios. Zhao et al. [5] examined control strategies under constant time headway distance, modeling non-ideal communication conditions including limited communication range, random packet loss, and time-varying delay. Their approach employed a distance-based dynamic topology and a robust controller that utilized multi-leader an follower information. Following this, Wang et al. [20] further advanced the approach by proposing a platoon following model based on dynamic weight optimization, which adaptively adjusted the weighting of incoming information. Their approach integrated realistic vehicle dynamics and demonstrated strong robustness under non-ideal communication conditions.

While these control approaches provide valuable theoretical foundations, they often rely heavily on accurate system modeling and incur significant computational overhead. Consequently, they are difficult to scale in dynamic and uncertain traffic environment characterized by rapidly changing velocities and nonlinear interactions."

> _[Section II.B, Related Work — MARL-based Platoon Control]_

"In recent years, MARL has gained significant attention in intelligent transportation systems due to its strengths in distributed decision-making, policy learning, and environmental adaptability [24], [25], [28], [29]. MARL has become a promising paradigm for cooperative control tasks, such as vehicle platooning. For example, Chen et al. [28] evaluated MARL frameworks using both local and global reward structures in platoons of three and five vehicles, and found that decentralized learning with local rewards achieved superior performance in terms of stability and responsiveness compared to centralized approaches.

However, the vast majority of existing MARL-based platoon control studies assume ideal V2V communication, free of delay and packet loss, and thus lack a comprehensive evaluation into the robustness of learned policies under realistic communication impairments. To address this gap, Wang et al. [25] proposed a delay-aware MARL framework based on a partially observable Markov game (POMG), capturing delay-induced uncertainties in platoon systems. Their simulations demonstrated improved platoon stability under time-varying delays. However, existing works still fall short of simultaneously addressing communication delays and packet losses in a unified MARL framework.

On dynamic communication topologies within MARL, researchers have explored inter-agent information correlations to construct adaptive communication topologies. Seminal algorithms including ITGCNet [30], Gated-ACML [31], I2C [26], and NeurComm [32] employ gating or attention mechanisms to determine when and with whom to communicate, thereby improving learning efficiency. In particular, Chu et al. [32] proposed a learnable protocol that enables agents to formulate distributed policies based on both local and neighbor information, partially mitigating the adverse effects of communication failure. Ding et al. [26] propose I2C, a dynamic communication framework where each agent learns to infer its communication targets from local observations via a prior network trained through causal inference. However, these methods primarily emphasize interagent information relevance while neglecting the dynamic variability of the communication environment, limiting their applicability under real-world communication environment.

To overcome these limitations, this paper proposes a DCT-MARL framework that jointly addresses communication delay and packet loss. The framework aims to substantially enhance the robustness and adaptability of connected vehicle platoon in non-ideal communication environment."
