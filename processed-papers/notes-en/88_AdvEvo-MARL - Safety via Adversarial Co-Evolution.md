# 88. AdvEvo-MARL: Shaping Internalized Safety through Adversarial Co-Evolution in Multi-Agent Reinforcement Learning

## Metadata
- **Title**: AdvEvo-MARL: Shaping Internalized Safety through Adversarial Co-Evolution in Multi-Agent Reinforcement Learning
- **Authors**: Zhenyu Pan, Yiting Zhang, Zhuo Liu, Yolo Yunlong Tang, Zeliang Zhang, Haozheng Luo, et al.
- **Affiliation**: Northwestern University; University of Illinois at Chicago; University of Rochester; Carnegie Mellon University
- **Venue**: arXiv preprint 2025 (Not specified for a peer-reviewed venue)
- **Link/arXiv**: arXiv:2510.01586v1 [cs.AI], 2 Oct 2025

## Taxonomy
- **Robustness / perturbation type targeted**: Safety / adversarial robustness of LLM-based multi-agent systems — jailbreak attacks, prompt injection, agent manipulation, message/communication corruption, user-instruction hijacking, and adversarial collaboration; defenders must resist evolving adversarial agents while preserving task utility.
- **Method paradigm**: Adversarial co-evolutionary MARL; minimax (max-defender / min-attacker) game objective; REINFORCE++ policy optimization with a public (group-level mean-return) baseline; attacker SFT warm-up + adversarial RL; internalized (intrinsic) safety rather than external guard modules.
- **Keywords**: LLM multi-agent systems, jailbreak/safety, adversarial co-evolution, MARL, public baseline, attacker-defender game

## TL;DR
AdvEvo-MARL internalizes safety into LLM task agents by jointly (co-)evolving attacker agents (which synthesize evolving jailbreak prompts) and defender agents (which both resist attacks and complete tasks) under an adversarial minimax MARL objective, using a group-level public baseline for lower-variance advantage estimation; it keeps attack-success rate below ~20% (vs. up to 38.33% for baselines) while preserving or improving task accuracy, without external guard agents.

## Problem & Motivation
LLM-based multi-agent systems (MAS) are powerful at planning, tool use, and role coordination, but their openness and interaction complexity expose them to jailbreak, prompt-injection, and adversarial-collaboration attacks; the complex inter-agent dynamics and possible unauthorized/adversarial agents expand the attack surface far beyond isolated single agents. Existing defenses fall into two lines: (i) self-verification, where each agent pre-filters unsafe inputs — but a standalone agent lacks the capacity to detect cross-agent unsafe chains and delegation-induced risks; and (ii) external guard/inspector modules — which add system overhead and create a single point of failure (once compromised, system-wide safety collapses), and scale poorly. Naively training agents individually overlooks the collaborative dynamics needed for multi-agent defense, and static-dataset safety training overfits and generalizes poorly against adaptive adversaries. The paper argues safety should instead be internalized into each task agent through adversarial co-evolution.

## Robustness Setting
- **Threat model / uncertainty set**: Attacker agents attempt to compromise the system's safety guardrails by generating and refining jailbreak/adversarial prompts; three representative attack scenarios are studied — agent manipulation (NetSafe, injecting "dark traits" into agent profiles), message corruption (AutoInject, injecting adversarial prompts into inter-agent messages), and user-instruction hijacking (UserHijack). Attackers are dynamic/adaptive (evolving via RL) rather than drawn from a fixed pool. Defenders must resist attacks while preserving task performance.
- **Setting**: Mixed competitive/cooperative — competitive between attacker and defender groups (zero-sum-style minimax objective), cooperative within each functional group; modeled as a partially observable Markov game; online adversarial RL post-training of LLM agents; multiple distinct backbone models trained collaboratively (not single shared-parameter model).

## Method
- Formulate the agent interaction as a partially observable Markov game G = (S, {Aᵢ}, P, {Oᵢ}, γ, T); agents are partitioned into disjoint attacker set A and defender set D, and the objective is the minimax game max over defender policies / min over attacker policies of the expected difference between defenders' and attackers' rewards (Eq. 2). For LLM agents, an action is generating a complete response (token sequence), not a single token.
- Attacker warm-up: build a paired dataset D_adv of (x_behavior, x_attack) from ~1,000 sampled harmful behaviors rewritten with representative jailbreak strategies, synthesize multi-step reasoning traces with an advanced reasoning model, filter invalid traces via LLM-as-judge (~4,000 high-quality samples), and SFT/imitation-learn attackers to seed jailbreak knowledge and accelerate early exploration.
- Co-evolutionary RL: jointly optimize attackers and defenders with REINFORCE++; attackers rewrite/refine prompts into more potent attacks while defenders learn robust safety behaviors against evolving threats; trains multiple backbone models collaboratively for genuine co-evolution.
- Public baseline for advantage estimation: each agent's advantage is its return minus the mean return of its own role group (b_A for attackers, b_D for defenders; Eqs. 3–4), reducing variance, enabling learning from peers, and strengthening intra-group cooperation. The PPO/REINFORCE++ loss adds importance-sampling ratio clipping and a KL term to a reference policy (Eq. 5).
- Reward modeling (Eq. 6): attackers rewarded by whether the final system output achieves the malicious goal (γ_f·f − α_s·s); defenders rewarded at both local-response and global-system levels combining safety s, task utility t, and format compliance f (α_s·s + β_t·t + γ_f·f). Safety/task rewards are +1 (safe/correct) or −1; format reward +0.5 / −0.1. Training prioritizes safety in the first half (α_s=1, β_t=0.5) then reverses to emphasize task performance.

## Theoretical Contributions
None / mostly empirical. The paper states a game-theoretic minimax objective (Eq. 2) and a public-baseline advantage estimator, but provides no convergence, equilibrium-existence, or sample-complexity proofs; contributions are framework design and empirical validation.

## Experiments
- **Environment/Benchmark**: Three MAS topologies (Chain, Tree, Complete graph), all with three agents. Backbones: Qwen2.5 instruction-tuned 3B and 7B. Attack scenarios: NetSafe, AutoInject, UserHijack. Safety eval datasets: official NetSafe dataset, plus a 300-prompt adversarial pool sampled from JailbreakBench, Wild Jailbreak, and Strong Reject (used in AutoInject/UserHijack). Training tasks: 4,000 problems from MATH-500 (levels 3–5). Task benchmarks: AIME'24 & AIME'25 (math), LiveCodeBench v6 (coding), GPQA-diamond (general reasoning).
- **Baselines**: Vanilla instruction-tuned Qwen2.5 3B/7B (no safety training); Challenger (self-verification on every agent); Inspector (single external guard agent); plus proprietary references GPT-3.5 and GPT-4o-mini; ablations include a static-attacker baseline and a no-public-baseline variant.
- **Evaluation metrics**: Attack success rate (ASR); Contagion rate (CR) — fraction of agents exhibiting unsafe behavior during an episode (process-level safety); Task performance — Accuracy for math/general reasoning, Pass@1 for coding.

## Key Results
- AdvEvo-MARL achieves the lowest ASR and CR among open-source baselines across nearly all configurations; ASR stays below ~10% in chain/tree topologies and below a maximum of ~17.68% in the harder complete-graph topology, while some baselines reach up to 38.61% (tree) and CR up to 65.53% (complete graph). Under UserHijack, Challenger-7B even worsens to 38.33% ASR (a ~10% increase over its non-defended variant).
- Task utility is largely preserved or improved: at most ~3% accuracy drop for 3B variants; the 7B variant (trained only on math) outperforms its vanilla counterpart across all datasets, including out-of-distribution ones, showing safety training need not sacrifice utility.
- Dynamic attackers help: the MARL-based attacker yields ~12% lower ASR under NetSafe (and a ~4% task-utility gain) versus a static-attacker baseline; attacker-prompt diversity rises (non-monotonically) over training, coinciding with stronger, more generalizable defenders.
- The public baseline produces more stable, efficient learning — improved accuracy and controlled ASR, lower attacker reward / higher defender reward over time; without it, training is non-stationary and defenders shrink responses (~13.3% length drop in the last 50 steps), a defensive overcompensation that hurts task completeness. (Note: the abstract/contributions cite up to 18.33% safety improvement; the main text highlights ASR kept below 20% vs. baselines up to 38.33%.)

## Limitations & Future Work
- Largely empirical; no formal guarantees of convergence to or existence of the claimed attacker-defender equilibrium.
- All experiments use only three agents per system and Qwen2.5 3B/7B backbones; scalability to larger agent counts/models and broader attack types is not established.
- In the densely connected complete-graph topology, contagion rate (CR) remains substantial (often near 30%+), and absolute ASR is higher than in chain/tree, indicating residual vulnerability under high interconnectivity. Future work and broader generalization are not explicitly detailed beyond positioning AdvEvo-MARL as a standardized framework for safe-and-capable MAS.

## Relevance to Survey
A safety-oriented, LLM-era instance of the adversarial-training / minimax line of robust MARL. It sits on the "adversarial agents / communication attacks / safety" robustness axis and the "adversarial co-evolution + game-theoretic minimax" method line, extending the attacker-as-adversary paradigm (as in robust-MDP / robust-adversarial-RL and robust Markov games) to cooperative LLM multi-agent systems, where the adversary is a learnable agent rather than environment/model uncertainty. It connects robust MARL to MAS safety, jailbreak/prompt-injection defense, and RL post-training of LLMs (PPO/GRPO/REINFORCE++, MAPPO/QMIX-style MARL), and contributes a variance-reduction (public group baseline) technique relevant to stable adversarial multi-agent training.

## Related Work (verbatim excerpts from the paper)
> _[Section 2, Related Work — intro paragraph]_

"Our work builds on two main research lines. The first examines safety in MAS, where adversarial threats such as agent manipulation and message corruption motivates defenses like self-verification, guard agents, and peer inspection. The second explores multi-agent reinforcement learning (MARL), which has enabled coordinated training and has recently been applied to LLM-based systems. These perspectives motivate our proposed AdvEvo-MARL, which unifies safety and MARL by co-evolving attackers and defenders to embed intrinsic safety awareness into agents."

> _[Section 2.1, Safety in Multi-Agent Systems]_

"LLMs are known to exhibit safety vulnerabilities, especially when exposed to adversarial attacks. Equipping agents with external tools or memory systems further expands the attack surface (Raza et al., 2025; Chen et al., 2024). While multi-agent systems (MAS) built upon such agents demonstrate strong task-solving capabilities, they are also vulnerable to a wide range of threats, most commonly: (1) manipulating agents to induce malicious behaviors (Yu et al., 2024), and (2) corrupting communication messages or workflow execution (He et al., 2025; Zhang et al., 2024). To mitigate these risks, several defense strategies have been proposed. Some works leverage self-verification, encouraging each agent to assess the benignness of its inputs before responding (Fan & Li, 2025; tse Huang et al., 2025), while others employ a dedicated guard agent to monitor and rectify message flows (tse Huang et al., 2025). Another line of research collects safety-oriented interaction trajectories and trains graph neural networks to detect and correct unsafe responses (Wang et al., 2025). Furthermore, decentralized defenses have also been explored, where agents inspect one another to form peer-based protection (Fan & Li, 2025). Although these approaches provide partial safeguards, they face key limitations. Individual agents often lack the capacity to detect sophisticated attacks, while centralized guard agents introduce a single point of failure and impose computational overhead in complex systems. In contrast, we advocate embedding safety awareness directly into each agent through reinforcement learning, enabling intrinsic defense capabilities and fundamentally improving the robustness of MAS."

> _[Section 2.2, Multi-Agent Reinforcement Learning]_

"Reinforcement learning (RL) has proven effective in post-training LLMs (Shao et al., 2024; Team et al., 2025; Pan & Liu, 2025), with methods such as Proximal Policy Optimization (PPO) and Group Relative Policy Optimization (GRPO) yielding substantial performance gains (Shao et al., 2024). More recently, RL has also been applied to enhance agentic behaviors in language-based systems (Jin et al., 2025). Multi-agent reinforcement learning (MARL), exemplified by algorithms like MAPPO and QMIX (Kang et al., 2023; Rashid et al., 2020), extends RL to coordinated multi-agent settings (Liu et al., 2025). Several recent studies adapt MARL to LLM-based systems: one line of work applies MARL to improve collaborative agent behaviors in structured game environments (Park et al., 2025); another develops hierarchical MAS with high-level planners and low-level executors using parameter sharing to enhance meta-reasoning (Wan et al., 2025); yet another treats each Retrieval-Augmented Generation (RAG) module as an agent, applying MARL to jointly optimize task performance (Chen et al., 2025). However, most methods train a single backbone model with shared parameters across agents (Pan et al., 2025b), limiting true agent-level diversity. In contrast, our framework trains multiple distinct backbone models collaboratively under RL, enabling genuine co-evolution. Building on these advances, our work explores MARL as a vehicle to improve MAS safety. By co-evolving attackers and defenders in an adversarial learning environment, we embed safety awareness directly into task agents through continuous interaction and adaptation, fostering robust and generalizable defense capabilities."
