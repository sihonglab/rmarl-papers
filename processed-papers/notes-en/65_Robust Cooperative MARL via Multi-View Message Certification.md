# 65. Robust Multi-Agent Communication via Multi-View Message Certification

## Metadata
- **Title**: Robust Multi-Agent Communication via Multi-View Message Certification
- **Authors**: Lei Yuan, Tao Jiang, Lihe Li, Feng Chen, Zongzhang Zhang, Yang Yu
- **Affiliation**: National Key Laboratory for Novel Software Technology, Nanjing University, Nanjing, China; Polixir.ai
- **Venue**: arXiv preprint 2023 (A PREPRINT; arXiv:2305.13936v1)
- **Link/arXiv**: arXiv:2305.13936v1 [cs.MA]

## Taxonomy
- **Robustness / perturbation type targeted**: Communication / message perturbations (adversarial attacks on received messages; ℓ∞-norm bounded perturbations on all message channels at any time)
- **Method paradigm**: Certified robustness (interval bound propagation), multi-view variational autoencoder (MVAE) with product-of-experts, latent-space perturbation, value decomposition (CTDE), RADIAL-RL-style robust training
- **Keywords**: robust multi-agent communication, message certification, multi-view representation, MVAE/product-of-experts, interval bound propagation, MA-Dec-POMDP-Com

## TL;DR
The paper proposes CroMAC, a robust multi-agent communication method that models each received message as a "view" of the state, fuses views via a product-of-experts multi-view VAE, and uses interval bound propagation plus latent-space perturbation to give agents certified (guaranteed) lower bounds on state-action values so they can choose optimal actions under worst-case message perturbations on all channels.

## Problem & Motivation
Cooperative MARL relies on communication to coordinate under partial observability, but communication policies are vulnerable when deployed in message-perturbation environments. Prior robust-communication works rely on restrictive assumptions (e.g., only a limited number of message channels suffer perturbations, or no more than half the agents/channels are attacked), which limit efficiency in complex scenarios and are far from real-world conditions where all channels can be perturbed at any time. Existing approaches also lack formal robustness guarantees / certificates between each agent's received messages and its decision-making. CroMAC aims to obtain a robust communication policy where every messaging channel could suffer perturbations at any time, with a certificate guarantee.

## Robustness Setting
- **Threat model / uncertainty set**: A message adversary v(m): m → m̂ perturbs the messages received by each agent so that agent i acts via π(aᵢ | τᵢ, m̂ᵢ). The adversary's power is restricted to a perturbation set B = { m̂ | ‖m − m̂‖_p ≤ ϵ }, with experiments focusing on p = ∞. Perturbations are generated with FGSM (project m + Δ to B(m)). All N−1 message channels per agent may be attacked at any time.
- **Setting**: Fully cooperative; partially observable; formalized as a message-adversarial Dec-POMDP-Com (MA-Dec-POMDP-Com), an extension of SA-MDP to communication. Centralized Training with Decentralized Execution (CTDE); online learning.

## Method
- Model multi-agent communication as a multi-view (multi-modal) problem: for an N-agent system each agent receives N−1 messages, each treated as a view of the state. A product-of-experts (POE) multi-view VAE (MVAE) extracts a joint message representation z_msg from the received messages; the POE combines per-view Gaussian experts analytically (mean/variance via inverse-variance weighting).
- Obtain certified bounds between the joint message representation and each received message via interval bound propagation (IBP) under ℓ∞-norm attack of budget ϵ, propagating averages/residuals through the message-encoder MLP layers; the POE integration error is bounded using Harmonic Mean properties (weights clamped to [C_MIN, C_MAX]).
- During training, encode the state s into a latent variable z_st via a state VAE, then impose ℓ∞ perturbations of budget κϵ in this latent space to obtain a certificate guarantee between z_st and each state-action value Qᵢ(τᵢ, z_st ± κϵ; aᵢ), implemented on RADIAL-RL with an adversarial overlap loss L_adv (using Q_diff and Ovl terms over action-value bounds), optimizable by any value-decomposition method (VDN/QMIX/QPLEX).
- Approximate the certified state representation by minimizing the KL divergence between z_st (gradient-stopped) and z_msg, so certification transfers implicitly to each message and Q-value. The overall loss combines TD loss, the state-VAE loss L(ψ), the message-representation loss L(φ), and the indicator-gated robust loss L_adv. Robust training starts only after step T_r; shared local-network parameters avoid the lazy-agent problem. Execution uses only the message-aggregation module and trajectory encoder, decentralized.

## Theoretical Contributions
- Derivation of a certificate (interval) bound between received messages and the joint message representation via interval bound propagation, including a proof that the POE integration error is bounded using Harmonic Mean / Weighted Harmonic Mean properties (the integration error is limited to a constant ‖|W|_{p,:} − |W|_{q,:}‖₁/N times ϵ when W, b, mᵢ are bounded).
- Proof (by induction, Appendix A) that a product of a finite number of Gaussian experts is itself Gaussian with the stated mean/variance.
- Otherwise mostly empirical; no convergence or sample-complexity guarantees for the overall RL algorithm.

## Experiments
- **Environment/Benchmark**: Cooperative multi-agent benchmarks — Hallway (two instances: 4x5x6, 3x3x4x4), Level-Based Foraging (LBF: 3p-1f, 4p-1f), Traffic Junction (TJ: slow, fast), and two SMAC maps (1o10b vs 1r, 1o2r vs 4r). Implemented on QMIX by default, based on PyMARL2; mean and standard error over 5 random seeds.
- **Baselines**: QMIX (no message sharing), AME (Ablated Message Ensemble), Full-Comm (full communication, perturbation-free, treated as upper bound), and ablations CroMAC w/o robust and CroMAC w/o adv. Generality study integrates CroMAC with VDN, QMIX, QPLEX; Table 1 also lists REC.
- **Evaluation metrics**: Mean test win rate / success rate over timesteps; average test win rates under different perturbation conditions (Natural, Random, PGD, FGSM with several budgets), averaged over 1000 test episodes and 5 seeds; hyperparameter sensitivity (κ, C_MAX, α1, α2, α3) and varying agent sight ranges.

## Key Results
- Under message perturbations during testing, CroMAC exhibits higher robustness than other methods; CroMAC w/o robust suffers severe degradation, and AME also degrades severely in complex/severe perturbation conditions, indicating that overly restrictive constraints fail under strong perturbations.
- CroMAC w/o adv (tested perturbation-free) achieves coordination comparable to Full-Comm, showing the architecture itself does not cause much performance degradation; QMIX (no communication) is consistently the weakest, confirming communication is needed.
- Generalization (Table 1): AME can match or exceed CroMAC in the Natural setting and under random perturbations, but degrades drastically under altered budgets (e.g., FGSM (4)) or different attack models (PGD), whereas CroMAC maintains high performance across perturbation budgets/methods in most environments.
- As a plug-in, CroMAC substantially improves robustness of VDN/QMIX/QPLEX (e.g., on LBF:3p-1f under perturbations) and improves coordination robustness across different sight ranges; hyperparameter studies find κ=3 and C_MAX=0.1 best on Hallway:4x5x6.

## Limitations & Future Work
- The number of attacks is fixed during the training phase; generalization to other budgets/attack methods is evaluated only empirically.
- QPLEX shows instability when the robust loss is added (best result chosen for comparison); performance is sensitive to several hyperparameters (κ, C_MAX, α1, α2, α3).
- The policy is learned online; the authors note that learning a robust communication policy in offline MARL is challenging but valuable future work.

## Relevance to Survey
A representative entry in the "communication robustness / certified robustness" line of robust cooperative MARL. It extends single-agent certified-robustness ideas (CARRL, CROP, RADIAL-RL, SA-MDP / state-adversarial formulations) to the multi-agent communication setting by formalizing MA-Dec-POMDP-Com and importing interval bound propagation. It connects the certified-defense theme (AME, ROMAX, CROP, CARRL) with multi-view representation learning (MVAE/POE) and value-decomposition CTDE methods (VDN/QMIX/QPLEX), and explicitly contrasts with adversarial-communication and limited-channel assumptions (Blumenkamp & Prorok, Xue et al., AME).

## Related Work (verbatim excerpts from the paper)
> _[Section 2, Related Work — "Multi-Agent Communication"]_

"Multi-Agent Communication plays a promising role in multi-agent coordination under partial observability, which considers when to communicate with whom and what contents to share [93]. The early relevant works mainly consider designing different communication paradigms to improve communication efﬁciency [14, 54]. DIAL [14] is a simple communication mechanism where agents broadcast messages to all teammates, allowing the gradient to ﬂow among agents for end-to-end training with reinforcement learning. CommNet [54] proposes an efﬁcient centralized communication structure, where the outputs of the hidden layers from all the agents are collected and averaged to augment local observation. As the mentioned communication paradigm may cause message redundancy, some works employ techniques such as gate mechanisms [38, 10, 77] to explicitly decide whom to communicate with, or attention mechanisms [9, 39, 69] to weigh different messages. What messages to share among agents is another crucial issue. The most naive way is only to share local observations or their embeddings [14, 67], which inevitably causes bandwidth wasting or even degrades coordination efﬁciency. Towards a more efﬁcient communication protocol, some methods utilize techniques like teammate modeling to generate more succinct and efﬁcient messages [90, 91, 85]. For the robustness of message sharing in CMARL, Blumenkamp and Prorok [2] develop a new multi-agent learning model that integrates heterogeneous, potentially self-interested policies that share a differentiable communication channel to elicit the emergence of adversarial communications. Xue et al. [79] consider multi-agent adversarial communication, learning robust communication policy when some message senders are poisoned. A recent method named AME [56] is proposed to acquire a robust communication policy when less than half of the agents in the system sustain noise and potential attackers."

> _[Section 2, Related Work — "Robustness in Single Agent Reinforcement Learning"]_

"Moos et al. [41] involves perturbations that occur in different aspects in single agent reinforcement learning such as state, reward, policy, etc. Some prior methods introduce an adversary to achieve robustness via training the ego-system and the adversary in an alternative way [48, 44, 63, 87, 53]. RARL [48] picks out speciﬁc robot joints that the adversary acts on to ﬁnd an equilibrium of the minimax objective using an alternative learning adversary. RAP [63] and GC [53] improve RARL by learning population-based augmentation to the Robust RL formulation. However, while these approaches provide better robust policies, it has been shown that such approaches can negatively impact policy performance in non-adversarial scenarios. Moreover, many unsafe behaviors may be exhibited during online attacks, potentially damaging the system controlled by the learning agent if adversarial training occurs in a physical rather than a simulated environment. Other methods improve robustness by designing useful and appropriate regularizers in the loss function [42, 57, 31]. Zhang et al. [87] formulate the problem of decision making under adversarial attacks on state observations as SA-MDP and learn a state-adversarial policy for multiple DRL methods like DDPG and DQN. RADIAL-RL [42] trains reinforcement learning agents with improved robustness against lp-norm bounded adversarial attacks, showing superior performance on multiple benchmarks. The mentioned approaches achieve robustness compared to adversarial training, improving the sample efﬁciency as they need not train an auxiliary adversary. Furthermore, these mentioned methods lack theoretical guarantee, hastening some recent certiﬁcate robustness methods [50, 12, 71, 72]. CARRL [50] develops an online certiﬁably robust policy that computes guaranteed lower bounds on state-action values during execution to identify and choose a robust action under a worst-case deviation in input space due to possible adversaries or noise. CROP [71] gives a solid theoretical guarantee for robust reinforcement learning and applies function smoothing techniques to train a robust policy."

> _[Section 2, Related Work — "Multi-View (Modal) Representation Learning"]_

"Multi-View (Modal) Representation Learning aims to learn feature representations from multi-view data using different views' information. Its main difﬁculty is to explicitly measure the content similarity between the heterogeneous samples. How to solve this problem roughly divides multi-view representation learning into three methods: alignment representation [47], joint representation [6], as well as shared and speciﬁc representation [76]. The key ideas of these methods are the same, which is establishing a common representation space by exploring the semantic relationship among the multi-view data. One popular and promising way is to use generative models like VAE [25], which generate this representation space in two ways: cross-view generation and joint-view generation. The former learns a conditional generative model over all views by applying techniques like conditional VAE [52]. Nevertheless, the latter learns the joint distribution of the multi-view data. For example, MVAE [74] models the joint posterior as a product-of-experts (POE), and JMVAE [59] learns a shared representation with a joint encoder. Please refer to [80, 1] for a comprehensive review. After the representation space is established by multi-view learning, some approaches use it to solve the modality missing problem [35], or obtain a compact representation from incomplete views [75]. Li et al. [28] extend the partially observable Markov decision processes (POMDPs) to support more than one observation model and propose two solutions through observation augmentation and cross-view policy transfer in a reinforcement learning problem. DRIBO [13] leverages the sequential nature of RL to learn robust representations that encode only task-relevant information from observations based on the unsupervised multi-view setting. Kinose et al. [26] introduce a novel reinforcement learning agent for integrated recognition and control from multi-view observations. To the best of our knowledge, none of any MARL approaches use multi-view learning to train the communication policy. We take a further step in this direction to get a robust message representation."

> _[Section 2, Related Work — "Multi-agent Robustness"]_

"Robustness also plays a promising role in MARL [21], but suffer from extra challenges that do not appear in the single-agent setting, as interactions exist among agents [20], leading to new and speciﬁc considerations such as non-stationarity [45], credit assignment [64], and scalability [8] when improving the robustness of any multi-agent system [21]. One type of relevant work aims to investigate the robustness of a learned coordination policy. Lin et al. [32] ﬁrst learn an observation attacker via RL, then use it to poison one manually selected agent, showing the multi-agent system is vulnerable to observation perturbation. Guo et al. [21] recently do more comprehensive robustness testing on reward, state, and action for typical MARL methods like QMIX [51] and MAPPO [82]. As for robustness improvement in MARL, research is conducted on multiple aspects. Many prior works focus on designing an efﬁcient approach to learning a robust coordination policy to avoid overﬁtting to speciﬁc partners [62] or opponents [29]. Akin to considering the MDP in a single-agent setting (e.g., state, reward, action), R-MADDPG [88] considers the model uncertainty of an MARL system, then introduces the concept of robust Nash equilibrium. Hu et al. [22] apply a heuristic rule to investigate the robustness of MARL when some agents suffer from action mistakes, and utilize correlated equilibrium theory to learn a robust coordination policy. Robustness in multi-agent communication has also attracted some attention in recent years. Mitchell et al. [40] apply a ﬁlter based on the Gaussian process to extract valuable content from noisy messages. Tu et al. [61] study robustness at the neural network level for secure multi-agent systems. Xue et al. [79] model multi-agent communication as a two-player zero-sum game and apply the policy-search response-oracle (PSRO) technique to learn a robust communication policy. The most related work to ours is Ablated Message Ensemble (AME) [56], which assumes no more than half of the message channels in the system may be attacked, then introduces an ensemble-based defense method to achieve robustness. However, we will show that this approach performs poorly in complex scenarios, as the constraints may impede robust efﬁciency."

> _[Introduction — prior-work paragraphs]_

"Robustness has been widely investigated in single-agent reinforcement learning (RL) [41], and many works have applied different techniques to various aspects to investigate it. A prior popular way is to introduce an auxiliary adversary to play against the ego-system [48, 87, 63, 53], then model the process of policy learning as a minimax problem from the perspective of game theory [83], which may trigger performance deterioration or even unsafe behaviors when facing an unpredictable adversarial policy. Another kind of method tackles this issue by designing efﬁcient and useful regularizers in the training process [87, 42, 57, 73], showing efﬁcient robustness in various domains. Certiﬁcate-based methods furthermore apply some techniques like vector-ϵ-ball perturbations to obtain a certiﬁcate robustness guarantee during the training and testing phases [12, 71, 55]. However, the MARL problem differs considerably from the single-agent setting, with multiple agents interacting with others [11]."

"For the robustness of MARL, new challenges such as scalability [8] arise as multiple agents interact with others in the training phase. For example, in the auxiliary adversary training paradigm, the action space of adversary policy may grow dramatically with respect to the number of agents in an MARL system. Works on robust MARL should then consider both the robustness and the multi-agent speciﬁcity. Some works design efﬁcient mechanisms to obtain a robust policy to avoid overﬁtting to speciﬁc partners [62] or opponents [29], and others consider the Markov decision process (MDP) itself to get a robust policy in response to state [92], reward [88], and action [22, 23]. Nonetheless, the robustness of a communication policy is much more complex [93], as we should consider when to give what perturbations on which message channel(s) to adversarially train the communication policy. Prior works mainly investigate the emergence of adversarial communication [2], or impose constraints like a limited number of message channels [56, 79] suffering from message perturbations. These approaches make progress somewhat, but the constraints hinder the robustness's completeness and are also far away from the real-world condition, as all the message channels could sustain perturbations [36]. Even worse, these approaches lack formal robustness guarantees or certiﬁcates between each agent's received messages and decision-making."
