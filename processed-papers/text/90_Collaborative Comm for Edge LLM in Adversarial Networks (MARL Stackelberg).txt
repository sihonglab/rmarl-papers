Servicing in Adversarial Networks: An
MARL-Empowered Stackelberg Game Approach
Liqi Hong
, Shengli Pan

Abstract—With the rapid expansion of IoT and the advent
of the 6G era, ensuring efﬁcient and secure communication for
the edge large language model (LLM) servicing has become
a critical priority. However, malicious relay nodes injecting
delays pose a signiﬁcant threat to network performance and
security. This article proposes a novel framework combining
Stackelberg Game theory with multiagent reinforcement learning
(MARL) to mitigate communication delay injection attacks
in edge networks. By modeling the interaction between edge
devices and malicious nodes as a Stackelberg Game, where edge
devices act as followers optimizing relay strategies and malicious
nodes as leaders seeking disruption, our approach enables edge
devices to cooperatively identify and avoid malicious nodes.
The distributed MARL framework allows each edge device to
learn their optimal strategies independently, enhancing network
resilience. Experimental results demonstrate the effectiveness of
our scheme in effectively reducing the impact of malicious nodes
and improving the deployment capability of edge computing
services.
Index Terms—Collaborative communication, edge large lan-
guage model (LLM) servicing, multiagent reinforcement learning
(MARL), Stackelberg Game.

II. RELATED WORK
The rapid development of edge LLM servicing has under-
scored the critical role of communication quality in adversarial
edge networks. Recent surveys, such as [1], have iden-
tiﬁed key challenges in resource constraints, latency, and
privacy when deploying LLMs at the edge. Research has
focused on two main approaches: 1) optimizing bandwidth and
2) resource allocation under constraints, and enhancing secu-
rity against threats like delay injection attacks. For bandwidth
optimization, RL techniques have been widely adopted.
Reference
[7] integrated deep neural networks with tra-
ditional algorithms to address high-dimensional scheduling
problems [8], while [9] applied deep Q-networks for resource
allocation in federated and vehicular networks. However, these
methods rely on centralized control and struggle in multi-
controller scenarios with partial observability or conﬂicting
objectives.
To tackle distributed challenges, multiagent game theory and
efﬁcient LLM deployment techniques have been introduced.
References [10] and [11] employed cooperative learning to
optimize throughput and relay selection. Meanwhile, sparse
LLM architectures like MoE models have gained traction
for edge deployment due to their parameter efﬁciency.
For instance, [12] proposed an on-device inference engine
that dynamically manages expert weights in MoE LLMs
through storage hierarchy partitioning and adaptive preloading.
Similarly, [13] introduced a framework for customizing on-
device LLM serving via proxy submodel tuning, enabling
resource-efﬁcient ﬁne-tuning of adapters.
Recent studies have integrated federated learning (FL) and
encryption to mitigate security risks while balancing efﬁciency.
References [14] and [15] leveraged FL to protect raw data,
while [16] applied differential privacy to enhance model con-
ﬁdentiality. Others like [17] achieved to improve transmission
security through risk-aware task allocation and lightweight
protocols. However, these approaches either sacriﬁce efﬁ-
ciency for security or fail to address dynamic adversarial
conditions, such as malicious relay nodes. For example, delay
injection attacks can disrupt LLM inference timing, degrading
service quality despite resource optimization efforts.
Current approaches lack a holistic solution for edge LLM
Servicing that balances bandwidth optimization, adversarial
resilience, and computational efﬁciency. Most RL-based meth-
ods assume benign environments, while security-focused work

III. SYSTEM MODEL
A. End-to-End Cooperative Communication Model
We present an end-to-end communication network model
that integrates wireless and wired links for intelligent edge
computing. Data travels from the source node S to the
destination node D through base stations and a central server,
divided into four time slots. The process begins with wireless
transmission from S to a base station, followed by wired
transmission to the central server. Next, the data is wire-
lessly relayed to another base station and ﬁnally transmitted
to D.
To enhance intelligent services, our model enables each
edge node to carry a specialized subset of parameters from
a global MoE model. During transmission, data packets
encapsulate task-speciﬁc routing and MoE parameter selec-
tion information. For example, source node S may embed
expert routing indices into the payload, guiding relay nodes
to activate appropriate local experts for partial inference or
feature transformation. These heterogeneous parameter com-
binations allow nodes to collaboratively complete different
stages of LLM inference without cloud resources. This edge
LLM scheme supports function-speciﬁc transmission paths
(e.g., vision-language embedding), transforming communica-
tion into a multifunctional inference workﬂow. As such, the
communication network is no longer a passive data delivery
infrastructure but a distributed MoE-driven reasoning pipeline,
adaptive to both task heterogeneity and network threats.

B. Stackelberg Game Model
In edge risk environments, a Stackelberg game framework
is proposed to model end-to-end communication. Relay nodes,
expending energy to forward data, face continuous delay
injection attacks, while the source node bears the associated
energy costs. In this game, relay nodes and the source node are
players, making decisions based on the communication state.

Challenges in solving Stackelberg equilibria include nonlin-

due to time-varying channels. Some optimization methods are
proposed to address these: [20] offered exact and approximate

equilibria to PPAD-complete problems. In general, a sequential
Stackelberg model can employ the backward induction to
effectively analyze the equilibrium [23].
C. MARL for Stackelberg Games
The Stackelberg game model in cooperative communication
systems captures the strategic interdependence between relay
and source nodes. The relay node employs pricing strategies
to balance energy consumption and security risks, while
the source node strives to maximize transmission rates and
minimize costs. This mutual inﬂuence complicates achieving
an optimal equilibrium, as each node’s strategy affects the
other’s objectives, posing a signiﬁcant challenge in dynamic
settings where rapid adaptation is essential.
As illustrated in Fig. 2, our proposed framework models
the interaction between edge agents and malicious relay nodes
as a Stackelberg Game, where agents learn to select reliable
relay paths via decentralized actor–critic learning. This design
enhances the robustness and efﬁciency of LLM delivery at the
edge by enabling adaptive, cooperative decision-making in the
presence of delay injection attacks.
To make the service more ﬂexible and reduce the cost of
loading models, our system uses a MoEs service. Each edge
agent can load different expert models in advance. Based
on the communication situation and task needs, the system
can turn on or send speciﬁc expert modules. This allows the
system to switch functions when needed. For example, it can
choose between fast response or high security depending on
the current environment. In this way, the system is able to
keep a relatively communication cost.

IV. NUMERICAL EVALUATION
A. Experiment Setup
In our simulation environment, the edge intelligent com-
munication network comprises multiple source nodes, relay
nodes, and destination nodes. Relay nodes collectively facil-
itate the delivery of LLM service data across the network.
Each relay node has a maximum power limit of 2.2 W, with
a cost limit of 7.0 per watt. Each source node can use up
to 1.0 W of power. The distance between each source and
destination node is 150 units. The distance from the source
to each relay nodes is [85, 80, 75, 90, 85], and from the relay
nodes to the destination is [90, 110, 95, 100, 95]. The learning
process incorporates key parameters, including an update rate
(τ = 0.001), reward discount (γ = 0.95), and learning rates
of 0.001 and 0.005 for the actor and critic, respectively. The
model also sets α = 0.15, β = 0.0935, λ = 0.235, and γ =
0.3 for system tuning. The attack strength is set to a = 0.3. For
training the reinforcement learning model, we use a memory
capacity of 10 000 and a batch size of 128. For evaluations,
we compare to the following benchmarks.
1) Random: The source and relay nodes both choose
actions randomly. The relay randomly picks a base
station group to forward data and sets a random energy
price, ignoring attacks. The source node also randomly
decides how much energy to buy and performs actions
accordingly.
2) DQN: This is a value-based method using Deep
Q-Learning. It uses a neural network to model state-
action values, employing experience replay and a target
network for stable learning. DQN is designed for dis-
crete states, so we discretized continuous aspects for a
fair comparison.
3) Adaptive Greedy (Constrained Optimization): For a
more comprehensive benchmark, we also compare to an
adaptive greedy scheme, where a source node selects a
relay node and determines energy purchasing by solv-
ing an optimization problem under system constraints.
Speciﬁcally, the source node aims to maximize its
